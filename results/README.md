# Results directory

This directory is used for outputs generated by the ASTRA-Drug analysis workflow.

Most result files are not stored directly in the GitHub repository because they are generated from the analysis scripts and may be large or numerous.

## Purpose

The `results/` hierarchy contains intermediate and final outputs from the sequential analysis steps described in `RUN_ORDER.md`.

Examples include:

- quality-control summaries;
- normalized expression results;
- mouse ASTS source-signature files;
- human ortholog mapping results;
- DepMap ASTS scores;
- PRISM and GDSC2 association results;
- cross-screen drug-response summaries;
- transcriptome-wide ASTS associations;
- CRISPR dependency results;
- mitochondrial dependency analyses;
- mitochondrial drug-response analyses;
- leave-one-lineage-out analyses; and
- donor-sex interaction analyses.

## Generated output structure

Individual scripts create their own step-specific result directories.

Representative directories include:

    results/
    |-- qc/
    |-- 07_ASTS_human_v1/
    |-- 08_DepMap_ASTS/
    |-- 14_ASTS_transcriptome/
    `-- ...

The exact output paths used by each step are defined in the corresponding analysis scripts.

## GitHub versus Zenodo

GitHub contains the analysis code and reproducibility framework.

Selected processed and derived result tables supporting the manuscript were deposited separately in Zenodo. These files will include key outputs needed to reproduce the reported statistical results and figures without requiring redistribution of restricted third-party source datasets.

Processed and derived data underlying the analyses and figures are archived separately in Zenodo.

Dataset DOI: https://doi.org/10.5281/zenodo.23178149

A fixed archival release of the analysis code is also available in Zenodo.

Software DOI: https://doi.org/10.5281/zenodo.23179457

## Regenerating results

To regenerate the outputs, follow the analysis order described in:

    RUN_ORDER.md

Some steps require external datasets that must first be obtained from their original providers. See:

    data/README.md
